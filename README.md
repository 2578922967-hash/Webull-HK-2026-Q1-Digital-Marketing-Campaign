# Webull HK 2026 Q1 Digital Marketing Campaign

一个面向香港市场的数字营销策略作品集项目，围绕 Webull 的「零费率 + AI 投资助手」双引擎定位，设计覆盖认知、考虑、转化、留存全链路的整合营销方案。

## 项目定位

这是一个个人策略作品，目标是将市场洞察转化为可执行的增长方案，并通过明确的渠道策略与 KPI 体系验证商业可行性。

## 背景与目标

香港线上投资市场正在持续增长，用户结构明显年轻化：

- 18-45 岁投资者占比约 62%，是核心交易人群
- 线上交易渗透率预计在 2026 年达到 72.8%
- 用户对 AI 投资工具接受度较高，但对工具实用性和安全性仍存在顾虑

在此背景下，本项目的目标是：

1. 放大 Webull「真零费率」优势，降低用户对交易成本的敏感阻力  
2. 放大「AI 投资助手」效率价值，覆盖新手与进阶用户的不同需求  
3. 通过“合规背书 + 内容口碑”机制，降低用户对线上券商的信任门槛  
4. 建立从获客到留存的可衡量增长闭环

## 核心策略

### 1) 核心创意（Big Idea）

**投资从 0 开始，佣金也从 0 开始 —— 年轻人的第一支 AI 投资工具**

围绕“三个 0”构建价值主张：

- `0 佣金 + 0 平台费`：解决价格痛点
- `0 经验门槛`：用 AI 降低新手选股难度
- `0 心理负担`：用 SFC 合规与用户口碑建立信任

### 2) 受众分层与信息策略

- **新手小白投资者（18-30）**：强调“低门槛、可快速上手”
- **精明理财打工人（30-45）**：强调“省佣金、提效率”
- **科技依赖型投资者（28-35）**：强调“AI 能力、策略自由度”

### 3) 渠道与路径设计

- **种草层**：小红书 / Instagram / 校园媒体
- **决策层**：Facebook / YouTube（费率对比、工具演示、合规解读）
- **沉淀层**：本地财经论坛 / 社群运营
- **转化承接**：全渠道一键开户链接 + 简化开户流程

并配套 4 类互动机制：

- 社交话题互动（认知）
- AI 工具体验挑战（考虑）
- 开户激励（转化）
- UGC 忠诚计划（留存）

## 执行节奏（Q1 三阶段）

- **第 1 月（预热）**：痛点唤醒与品牌认知铺垫  
  目标示例：触达 `>=100k`、互动率 `>=2.5%`
- **第 2 月（启动）**：活动引爆与拉新转化  
  目标示例：开户 `>=2000`、挑战参与 `>=1500`
- **第 3 月（留存）**：口碑沉淀与用户活跃提升  
  目标示例：首次入金 `>=1500`、30 日留存 `>=35%`

## KPI 体系（Q1 预测）

- 品牌触达（Reach）：`2.5M - 2.6M`
- 提及量（Mentions）：`150`
- 提及率（SoM）：`>=2%`（理想 2.2%-2.5%）
- 下载 -> 注册：`50%-55%`
- 注册 -> 入金（Funded）：`18%`
